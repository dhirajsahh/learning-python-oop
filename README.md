# Python OOP

A beginner-friendly Python object-oriented programming notebook with examples and notes.

## Topics

- Python objects, classes, and object creation
- Constructors and instance methods
- Methods versus standalone functions
- `self` and how objects use it
- Dunder (magic) methods, including `__str__`
- Operator overloading with a `Fraction` class
- An interactive ATM example

## Getting started

Open [`basic.ipynb`](basic.ipynb) in VS Code with the Python and Jupyter extensions, or in Jupyter Notebook or JupyterLab. Run the cells in order. The examples use Python's standard library and need no additional packages.

The ATM example prompts for input when its cell runs.
